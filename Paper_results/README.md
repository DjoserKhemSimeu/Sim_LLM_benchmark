# Supplementary data for
## "A Testbed Framework for Estimating the Environmental Impact of Agentic AI Workflows in HPC"

This folder contains supplementary experiment outputs and figures related to the paper "A Testbed Framework for Estimating the Environmental Impact of Agentic AI Workflows in HPC".

Summary
-------
- Purpose: provide the raw and processed outputs produced by the benchmark runs, plus the evaluation artifacts used to generate the figures and analyses reported in the paper.
- Location: this repository subtree stores per-scenario experiment outputs and the notebooks/scripts used to analyze them.

Contents
--------
- `experiments_data/Sim_*/measure/data`
  - Contains the raw output CSVs and measurement logs produced by the benchmark runs for each simulation variant (e.g. Sim_Chuc, Sim_Grouille, Sim_Hydra, ...).
  - These files are the primary raw data used in the analysis (power traces, per-GPU logs, aggregated metrics).

- `experiments_data/Sim_*/images` (or `images` produced by the evaluation script)
  - Contains the figures generated by the evaluation scripts (time-series plots, boxplots, Sankey diagrams, impact bar charts, etc.).
  - Use these images for quick visual inspection or to reproduce figures in the paper.

- `measure/notebooks` (or `measure/notebooks/plot_generator.ipynb`)
  - Jupyter notebook(s) used to create the additional plots and analyses: raw results inspection, uncertainty analysis, statistical tests, and final aggregated impact calculations.
  - Open the notebook to reproduce the post-processing and plotting steps.

Quick usage
-----------
1. Inspect raw data:

   - Open the relevant CSV files under `experiments_data/Sim_*/measure/data` with your preferred tool (pandas, Excel, etc.).

2. View generated images:

   - Browse the `images` directories or open `experiments_data/Sim_*/images/*` to see the evaluation figures.

3. Reproduce plots/analysis (notebook) open `plot_generator.ipynb` (or the notebook present in `measure/notebooks`) and run the cells.

Notes and requirements
----------------------
- Large plots and some heavy processing steps may require a machine with enough memory and CPU; the notebook indicates any long-running cells.
- This folder is intended as supplementary material to the paper: use the notebook and raw data to reproduce, extend, or audit the analyses.
