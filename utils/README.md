# utils/

Contient utilitaires et helpers réutilisables.

Fichiers clés :
- `utils_file.py` : fonctions utilitaires de gestion de fichiers, lancement de scripts, et helpers de logging.

Conseils :
- Centralisez petites fonctions utilitaires ici plutôt que dupliquer.
- Vérifiez les dépendances internes avant d'extraire/utiliser une fonction dans un autre script.
